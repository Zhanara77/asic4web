# Assignment 4 — Forms and Validation

## Files
- `index.html` — Task 1: responsive train ticket form.
- `task2.html` — Task 2: AITU Hack 2026 registration and native HTML validation.
- `task3.html` — Task 3: corrected café reservation form.
- `styles.css` — shared styling.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser (or use the Live Server extension).
4. Open `task2.html` and `task3.html` to test the other forms.
5. Resize the browser to 375px and 1280px for Task 1.
6. For Task 2, test both valid and invalid values listed in the report. No JavaScript and no `novalidate` are used.

## Notes
- Task 1 uses Bootstrap 5.3, custom CSS, connected labels, required fields, keyboard-operable radio buttons and a reset button. Button order remains Find trains then Clear in the HTML; flex column-reverse presents Find trains above Clear on a phone.
- Task 2 uses native HTML attributes (`type`, `required`, `min`, `max`, `step`, `minlength`, `maxlength`) and does not use `pattern` or JavaScript.
- Task 3 fixes labels, input types, names, required fields, responsive layout, radio grouping and the submit button.
- Before submission, personalize the report with your name/group, take screenshots of your actual pages at 375px and 1280px, and push the project to your own GitHub repository.
